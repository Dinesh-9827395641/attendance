📖 How to Use

This app runs entirely in your browser. All data stays in this HTML file. Multiple classes with separate logins are supported.

1 Logging In

There are two login types. Ask your school administrator if you don't have your login details.

  • 👑 Master — full access to all classes.
  • 👨‍🏫 Class — pick your class and log in.

2 Creating Classes (Master)

Go to Classes tab. Type a name, optionally set a password, click ➕ Add Class.

Actions per class: Login, Rename, Reset Password, Delete.

⚠ Passwords are never shown on screen. Reset Password sets a new one.

3 School & Session (Master)

Type the school name, set session dates, add houses. Session is shared by all classes.

4 Adding Students

Master: pick a class from the header dropdown. Class login: your class is already active.

5 Attendance Register

Choose section and month, click a white cell to cycle blank → P → A → blank.

6 Colour Codes

  • 🟢 P — Present
  • 🔴 A — Absent
  • 🟨 Sunday — locked
  • 🟥 Holiday — locked
  • ⬜ Grey — Not enrolled / outside session

7 Reports

  • Monthly Summary — every student's % for picked months
  • Low Attendance — students below a threshold
  • Consolidated (Master) — all classes side by side

8 Saving & Backup

  • 💾 Save — write data back into the HTML file
  • ⬇ Backup — download a JSON backup
  • ⬆ Restore — reload data from a backup

9 Students Who Leave

Don't delete — click Left and enter the last date. Click Restore to bring them back.

10 Troubleshooting

  • No students in register? Check the month and section filter.
  • Can't click cells? Check the month is within session and after admission date.
  • Forgot a class password? Master can reset it from Classes.
